about=Geosian (GreenCityControl) es una plataforma de gestión de datos geoespaciales para servicios urbanos. Este complemento convierte QGIS en un cliente más de la plataforma: registra un proveedor de datos propio que habla con la API de Geosian, de modo que las capas no son ficheros ni una conexión directa a la base de datos, sino datos vivos del servidor. Los formularios se generan a partir del esquema dinámico de cada capa.
